¿Qué es una máquina virtual?

Una máquina virtual (VM) es un computador simulado por software. Tiene su propia CPU virtual, memoria, disco y tarjeta de red, y ejecuta su propio sistema operativo como si fuera un equipo físico independiente.

El equipo real se llama anfitrión (host). Cada sistema que corre dentro de una VM se llama invitado (guest). Un anfitrión puede tener varios invitados a la vez, y lo que pase dentro de uno no afecta a los otros.

El hipervisor

El hipervisor (o VMM, Virtual Machine Monitor) es el software que crea las VM y reparte entre ellas los recursos físicos: decide cuántos núcleos, cuánta RAM y cuánto disco recibe cada una.

Ventajas

  • Aprovecha mejor el hardware: varios servidores en una sola máquina.
  • Aislamiento: un fallo o virus en una VM no daña las demás.
  • Snapshots y clones para respaldar y recuperar rápido.
  • Portabilidad: la VM se mueve de un equipo a otro.
  • Ahorro en energía, espacio y equipos.

Desventajas

  • Algo menos de rendimiento que el hardware directo.
  • Si falla el anfitrión, caen todas sus VM.
  • Necesita bastante RAM y almacenamiento.
  • Algunas licencias de software cobran por VM.

Casos de uso

  • Laboratorios educativos: practicar Linux o redes sin tocar el PC real.
  • Pruebas de software: probar una aplicación en varios sistemas operativos.
  • Consolidación de servidores: una empresa pasa de 10 servidores físicos a 2.
  • Computación en la nube: AWS, Azure y Google Cloud venden VM por horas.
  • Ciberseguridad: analizar archivos sospechosos en un entorno aislado (sandbox).
  • Software heredado: mantener programas que solo funcionan en sistemas antiguos.

Práctica guiada: crea tu primera VM

Con VirtualBox (gratuito) en tu propio computador:

  1. Descarga e instala VirtualBox desde virtualbox.org.
  2. Descarga la imagen ISO de una distribución Linux, por ejemplo Ubuntu.
  3. Pulsa Nueva, ponle nombre y elige el tipo Linux / Ubuntu (64-bit).
  4. Asigna 2 vCPU, 4 GB de RAM y un disco virtual de 25 GB.
  5. En Almacenamiento, monta la ISO en la unidad óptica virtual.
  6. Inicia la VM e instala el sistema operativo.
  7. Toma un snapshot llamado “Instalación limpia”.
Requisito: activa la virtualización por hardware (Intel VT-x o AMD-V) en la BIOS/UEFI si VirtualBox lo pide.

Glosario

Anfitrión (host)
Equipo físico donde corre el hipervisor.
Invitado (guest)
Sistema operativo que se ejecuta dentro de una VM.
Hipervisor
Software que crea y administra máquinas virtuales.
Bare-metal
Instalado directamente sobre el hardware, sin sistema operativo intermedio.
Snapshot
Copia del estado de una VM en un momento dado.
ISO
Archivo imagen de un disco de instalación.
NAT / Bridge
Modos de red: NAT comparte la IP del anfitrión; puente da a la VM su propia IP en la red.
VT-x / AMD-V
Extensiones del procesador que aceleran la virtualización.
Contenedor
Entorno aislado que comparte el kernel del anfitrión; más ligero que una VM.
